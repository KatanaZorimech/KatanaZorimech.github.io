# 桌面宠物（阶段 D）

透明置顶宠物 + 交互 + 旁侧聊天 / 设置 + **选区摘要 / 翻译**（快捷键 + 剪贴板）。

## 运行

```bash
npm install
npm run build
npm start
```

## 配置

右键 → **设置**：填写 API Key / Base URL / 模型 / 温度，以及选区快捷键。

## 选区摘要 / 翻译

1. 首次使用会弹出权限与隐私说明，点「我知道了」。
2. 在其他应用中选中文字。
3. 使用快捷键或右键菜单：
   - **动作菜单**（选摘要或翻译）：`Ctrl/Cmd+Shift+D`
   - **摘要所选**：`Ctrl/Cmd+Shift+S`
   - **翻译所选**：`Ctrl/Cmd+Shift+T`
4. 结果出现在聊天气泡中。

默认会先模拟复制再读剪贴板，并尽力恢复原剪贴板。macOS 需授予「辅助功能」权限；也可关闭「先模拟复制」并手动 Cmd/Ctrl+C。

**隐私**：选中文本会发送到你配置的 LLM 接口。
