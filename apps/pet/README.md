# 桌面宠物（阶段 E · 打磨）

透明置顶宠物：交互表情、旁侧聊天、OpenAI 兼容 LLM、选区摘要/翻译。默认界面为**简体中文**。

## 安装与运行

### 开发

```bash
# 仓库根目录
npm install
npm run build
npm start
```

### 打包（需在对应 OS 上执行）

```bash
npm run pack    # 目录产物 → apps/pet/release/
npm run dist    # 安装包（macOS dmg/zip，Windows nsis）
```

正式分发建议配置代码签名；内测可跳过。

## 配置 LLM

右键宠物 → **设置**：

- API Key / Base URL / 模型 / 温度
- 选区快捷键、是否先模拟复制
- **开机自启**（可选）

配置保存在本机 Electron `userData/desktop-pet-settings.json`，**不会上传到我们的服务器**。

## 选区摘要 / 翻译

| 功能 | 默认快捷键 |
|------|------------|
| 动作菜单（选摘要/翻译） | `Ctrl/Cmd+Shift+D` |
| 摘要所选 | `Ctrl/Cmd+Shift+S` |
| 翻译所选 | `Ctrl/Cmd+Shift+T` |

也可右键 → **摘要所选** / **翻译所选**。

1. 首次使用会显示权限与隐私说明。
2. 在其他应用中选中文字。
3. 默认会模拟复制后读剪贴板（并尽力恢复原剪贴板）；也可关闭该选项并手动复制。

## 权限说明（macOS / Windows）

- **macOS 辅助功能**：若开启「先模拟复制」，请在「系统设置 → 隐私与安全性 → 辅助功能」中允许本应用，否则模拟 Cmd+C 可能失败。
- **Windows**：模拟 Ctrl+C 通常无需额外授权；部分安全软件可能拦截。
- **剪贴板**：应用会读取（及短暂改写后恢复）剪贴板文本以获取选区。

## 隐私

- **API Key**：仅本地存储。
- **聊天与选区文本**：发送到你在设置中配置的 LLM 接口（OpenAI / DeepSeek 等），用于生成回复；请勿选择敏感内容。
- **日志**：错误与崩溃信息写入本机 `userData/logs/`（JSON 行），不含主动上传。

## 性能与占用

- 单窗口 + 托盘；无后台轮询定时器。
- Electron 应用空闲内存通常约 **100–250MB**（视系统与 Chromium 版本而定），属壳层基线，非宠物逻辑本身泄漏。
- 动画使用 CSS；空闲时仅 idle 循环。

## 已知限制 / 后续

- 英文 UI 切换：列为后续增强（当前仅简体中文）。
- Linux：可运行但非首发目标；开机自启依赖桌面环境。
- 多宠物 / 语音 / Live2D / 本地大模型：不在 v1 范围。
