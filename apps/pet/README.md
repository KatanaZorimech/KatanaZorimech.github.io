# 桌面宠物（阶段 B）

透明置顶无边框窗口 + FSM 表情交互 + 右键菜单。

## 本地运行

```bash
# 仓库根目录
npm install
npm run build
npm start
```

## 交互

| 操作 | 反馈 |
|------|------|
| 拖动 | `drag`：倾斜、瞪眼、汗珠 |
| 单击 | `click`：挤压 + 眯眼 |
| 双击 | `happy`：跳动 + 爱心 |
| 右键 | 菜单 + 短暂表情 |

右键菜单（简体中文）：置顶、打开聊天、摘要、翻译、设置、音效、退出。  
聊天 / 摘要 / 翻译 / 设置为占位提示；置顶与退出可用。音效默认关闭。

## 打包

```bash
npm run pack -w @desktop-pet/pet
```
