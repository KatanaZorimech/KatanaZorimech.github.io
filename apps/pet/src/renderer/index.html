设置

Key 仅保存在本机用户目录。选区摘要/翻译会把剪贴板文本发送到你配置的 LLM 接口（不会发到我们的服务器）。macOS 模拟复制需在「系统设置 → 隐私与安全性 → 辅助功能」中授权。英文界面为后续可选增强。

选区功能说明

  1. 先在其他应用中选中文字。
  2. 使用快捷键或右键「摘要所选 / 翻译所选」。默认会模拟复制后读取剪贴板。
  3. macOS：请到「系统设置 → 隐私与安全性 → 辅助功能」允许本应用，否则模拟复制可能失败（可改为手动复制）。
  4. 隐私：选中的文本会发送到你在设置中配置的 LLM 服务（不会发到我们的服务器）。请勿选择敏感信息。
  5. 过长文本会截断至约 4000 字后再处理。

默认快捷键：动作菜单 Ctrl/Cmd+Shift+D · 摘要 Ctrl/Cmd+Shift+S · 翻译 Ctrl/Cmd+Shift+T
